WindBot AI 에디터 — 배포용 안내
=================================

■ 무엇인가요?
  EDOPro 의 AI(WindBot)가 어떤 플레이를 할지 "유희왕식 규칙"으로 편집하고,
  그 AI로 듀얼할 수 있게 해주는 데스크톱 도구입니다.

■ 실행 방법
  1) 이 zip 을 원하는 폴더에 압축 해제
  2) WindBotAIEditor.exe 실행
  3) 처음 한 번, EDOPro 폴더(EDOPro.exe 가 있는 폴더)를 선택
     - 예: D:\edopro
     - 경로는 %APPDATA%\WindBotAIEditor\settings.json 에 저장되어 다음부터 묻지 않습니다
  4) 이후 자동으로 다음을 불러옵니다
     - EDOPro\WindBot            (엔진/덱/bots.json)
     - EDOPro\repositories\languages\**\*.cdb  (한국어 카드 DB 전부)
     - EDOPro\script\*.lua       (카드 스크립트)

■ 요구 사항
  - Windows 10 / 11 (64비트)
  - EDOPro 설치본 (WindBot 폴더 포함)
  - .NET 설치는 필요 없습니다 (런타임 포함 단일 실행 파일)
  - 플러그인 컴파일에는 Windows 기본 내장 csc(.NET Framework 4.x) 를 사용합니다

■ 기본 사용 순서
  1) [덱] 탭
     - 왼쪽: 덱 선택 또는 새 덱 생성
     - 오른쪽: 덱 내용(.ydk) 편집, 카드 추가(이름 검색), 이름→ID 변환
  2) [⚙ AI 설정] 탭 — 엔진 설정 + 저장/컴파일
     - 위: 엔진명 / 가위바위보 · 선공/후공 / 대사 / 체인 중복 기준 / 열 회피
           (창이 낮으면 [설정 접기] 로 공간을 넓힘)
     - 아래: [규칙 저장][규칙 불러오기][소스 미리보기][생성 + 컴파일] + 현재 규칙 요약 + 빌드 로그
  3) 규칙 탭 ①~⑤ (최상위 탭 — 각각 따로 열립니다):
         ① 행동·조건 : 무엇을 할지 (일반소환/특발/발동/세트/배틀 등) + 조건(AND/OR)
                      · [소환 존] 열: 메인/엑스트라 몬스터 존 중 어디에 소환할지
        ② 선택 규칙 : 효과 대상·소재·표시형식·존 선택 시 무엇을 고를지
                      · [정책]=테마 카드 우선 → [테마]/[몬스터만]/[제외 카드] (없으면 다음 규칙으로 폴백)
                      · [옵션desc] = SelectOption 옵션 문자열 ID (효과 선택 1607328402 / 위·아래 1607328404)
                      · [상황]=SelectOption 일 때만 [옵션desc] 칸이 보입니다
                      · 조건 그리드의 [부정(!)] = !(조건), [몬스터만] = 테마 몬스터만
        ③ 금지 규칙 : 특정 카드의 특정 행동 차단 (턴 조건·효과번호 지원)
                      금지 행을 선택하면 아래 [예외 조건] 표가 열립니다.
                      · 조건 해석 = "조건 충족 시 허용(예외)" / "조건 충족 시에만 금지"
                      · 종족 열: 내/상대 필드에 특정 종족 몬스터가 있는지
                      · 테마 열: 필드/패/묘지에 특정 테마(아키타입) 카드가 있는지 (전체 = 테마 무관)
                      · 종족/테마 칸은 카드명처럼 타이핑해서 검색 (Enter 또는 클릭으로 선택)
                      · 이벤트 조건(드로우/서치/소환/묘지…)은 이름에 나/상대가 포함되어 있습니다
                      · [체인당 N회 제한]: 카드ID 0 = 전체, [횟수] = 허용 횟수
                      · 상대 발동 종류 조건: 상대 몬스터/마법/함정 효과 발동에 반응할 때
        ④ 트리거    : 완성 트리거(그룹 AND/OR), 상대 발동 트리거
        ⑤ 전개 루트 : 순서대로 실행할 플레이 단계 (좌 루트 목록 · 우 단계 카드 · 아래 조건)
                      · [선공 전개] [후공 전개] 로 트랙을 바꿔 각각 N벌씩 저장
  - 상단 [봇 대사] 탭: WindBot\Dialogs\*.json 편집 (환영/턴/공격/발동/체인 …)
    · 엔진 설정의 [대사] 콤보에서 고르면 그 엔진만의 대사가 됩니다
    · 대사 내용은 봇 재시작만으로 반영, 파일 이름을 바꾸면 [생성 + 컴파일] 필요
    · EDOPro 가 실행하는 봇은 default.json 을 쓰므로 [default.json 에 적용] 사용
  3) [생성 + 컴파일] → EDOPro\WindBot\Executors\<엔진명>Executor.dll 생성
  4) [봇 목록] 탭에서 항목 추가 → 저장
     - [배포용 ZIP 내보내기] : 실행기 DLL + 덱 + 대사 + bots.json 항목 + 설치 스크립트를 ZIP 하나로
  5) EDOPro 실행 → 로비에서 AI 선택 → 듀얼

■ 화면 배치
  - 창은 최소 1100x700 까지 줄일 수 있습니다 (그 이하로는 줄지 않습니다)
  - 탭 순서: 덱 · ⚙ AI 설정 · ① 행동·조건 · ② 선택 규칙 · ③ 금지 규칙 · ④ 트리거 · ⑤ 전개 루트
              · 봇 목록 · 봇 대사 · 카드 DB/Lua · 검증/실행  (규칙 탭은 각각 최상위 탭)
  - 덱 목록과 덱 레시피 사이의 회색 경계선을 드래그하면 폭이 바뀝니다
  - 덱 레시피와 [덱 내 카드 검색] 사이 경계도 위아래로 드래그됩니다
  - [⚙ AI 설정] 위쪽 설정 카드는 [설정 접기] 로 접어 공간을 넓게 쓸 수 있습니다
  - [⚙ AI 설정] 의 "자유 플레이 시 마법/함정도 세트" 체크 → 종류(전체/함정만/속공만) + 제외 카드
    (패트랩 등 세트하면 안 되는 카드는 카드명으로 검색해 [추가])
  - [⚙ AI 설정] 의 "자유 플레이 시 엑스트라 덱 몬스터를 릴리스/제물로 쓰지 않음" (기본 ON)
    → 엑시즈/링크 등을 제물로 바치는 사고를 막습니다 (소재 사용은 그대로 허용)
  - ⑤ 전개 루트는 왼쪽 루트 목록 / 오른쪽 단계 카드 / 아래 조건 그리드로 나뉩니다

■ 꼭 알아두세요
  - 규칙을 바꾼 뒤에는 반드시 [생성 + 컴파일] 후 WindBot 을 재시작해야 반영됩니다
    (WindBot 은 시작할 때 DLL/덱을 한 번만 읽습니다)
  - 엔진 이름과 덱 이름은 같아야 합니다 (예: raisemoon ↔ AI_raisemoon.ydk)
  - 규칙 파일은 EDOPro\WindBot\Executors\_src\<엔진명>Executor.rules.json 에 저장됩니다
  - bots.json 은 저장 시 _backup 폴더에 자동 백업됩니다

■ 화면 모드
  - 상단 오른쪽 "다크 모드" 체크박스로 라이트/다크를 전환합니다 (설정에 저장됨)

■ 카드 DB / Lua 탭
  - 한국어 기준으로 repositories\languages 의 모든 cdb 를 함께 검색합니다
  - 카드 효과의 SetDescription 값(효과번호)과 strings.conf 설명을 함께 보여줍니다
  - "효과번호 기록" 체크 후 빌드하면, 발동 시 카드ID/효과번호가 콘솔에 출력됩니다
  - 금지 규칙의 "턴"은 모든 금지 유형에 적용됩니다 (내 턴에만 / 상대 턴에만 / 턴 무관)
    → 금지 규칙의 효과번호를 정확히 지정할 때 사용하세요

■ 문제가 생기면
  - 빌드 로그에 csc 오류가 보이면 그 문장을 그대로 전달해 주세요
  - 듀얼에서 AI가 멈추거나 잘못 선택하면, 어떤 카드/상황이었는지 알려주세요
